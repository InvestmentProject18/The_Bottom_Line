# The_Bottom_Line
For my CSAEA capstone sprint, I built a prototype Genetic Algorithm in Python to serve as the foundation for a system designed to optimize tax values and help lower the poverty line. Modeling effective economic policy requires searching through massive, complex datasets to find ideal tax bracket configurations. This starter implementation focuses on validating the core evolutionary mechanics on an eight-element array to prove that the algorithm can consistently converge on an optimal target configuration before adding real socio-economic variables. The codebase uses an object-oriented problem class to manage population state and genetic parameters alongside a main genetic_algorithm loop. The recipe_success objective function measures performance by calculating the negated Manhattan distance between a candidate solution and the target parameter vector, where a score of zero represents a fully optimized policy state. In the fitness method, raw scores are converted into reproduction probabilities so that better-performing candidates are more likely to pass down their traits. I included a dynamic buffer in this step to prevent division-by-zero errors when scores homogenize across a generation. Parents are selected using probability-weighted sampling through NumPy, and a single-point crossover function combines segments from two parents to generate offspring. The mutate function then applies a twenty percent mutation probability to swap in new valid integers, which keeps the population diverse and prevents the search from getting stuck in local optima. Running the simulation across 200 generations with a population of 100 individuals demonstrated how the system steadily improves its best and average scores over time. The biggest challenge was balancing selection pressure, as early runs tended to let top candidates dominate the gene pool too quickly. Tuning the mutation rate and score buffer solved this issue. Ultimately, this starter project successfully verifies the core evolutionary framework, giving me a solid, working codebase to connect to realistic tax models and socio-economic data in the next phase.
