# The_Bottom_Line
For this CSAEA capstone sprint project, I built a custom Genetic Algorithm (GA) in Python to find an optimal sequence matching a specific target configuration, [1, 3, 2, 1, 1, 4, 1, 1], where each element represents a gene bounded between 1 and 4. Instead of using brute-force enumeration, the program models biological evolution through fitness evaluation, weighted parent selection, crossover recombination, and stochastic gene mutation to guide a randomly generated population toward the exact target sequence. The codebase centers around an object-oriented problem class that manages population state and parameters, driven by a main genetic_algorithm execution loop. The recipe_success objective function calculates the negated Manhattan distance between a candidate solution and the target vector, where a score of zero represents a perfect match. In the fitness() method, these raw scores are normalized into reproduction probabilities so that fitter candidates are more likely to be selected for breeding, complete with a dynamic buffer to avoid division-by-zero errors when candidate scores in a generation are identical. Parents are chosen using probability-weighted sampling via NumPy, and single-point crossover (reproduce) combines segments from both parents into an offspring. Next, mutate() applies a 20% mutation probability to randomly replace a gene with a new valid integer, maintaining genetic diversity and preventing premature local convergence. The loop runs for up to 200 generations with a population size of 100, tracking top scores and population averages until the exact match is found. The main challenge was managing selection pressure; early tests showed that top candidates dominated too quickly, so tuning the mutation rate and score buffer was essential to reaching the target. Ultimately, running the script with random seed 42 demonstrates how evolutionary heuristic search can efficiently solve discrete sequence optimization problems.
